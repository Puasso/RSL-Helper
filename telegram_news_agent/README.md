# Telegram News Agent

Агент собирает посты из заданных Telegram-каналов, группирует новости с похожим смыслом, исключает дубли и отправляет в целевой чат краткую выжимку.

## Что умеет

- читать последние сообщения из нескольких Telegram-каналов;
- очищать технический шум: ссылки, короткие посты, пустые сообщения;
- считать семантическую близость через embeddings;
- объединять похожие сообщения в один новостной кластер;
- формировать полную, но короткую сводку по каждому кластеру;
- отправлять итоговый дайджест в Telegram-чат, канал или «Избранное».

## Быстрый старт

1. Создайте приложение Telegram на <https://my.telegram.org/apps> и получите `api_id` и `api_hash`.
2. Скопируйте конфигурацию:

   ```bash
   cp telegram_news_agent/config.example.yaml telegram_news_agent/config.yaml
   ```

3. Заполните `telegram_news_agent/config.yaml` своими каналами и целевым чатом.
4. Установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r telegram_news_agent/requirements.txt
   ```

5. Добавьте ключ OpenAI:

   ```bash
   export OPENAI_API_KEY="sk-..."
   ```

6. Запустите агента:

   ```bash
   python telegram_news_agent/agent.py --config telegram_news_agent/config.yaml
   ```

При первом запуске Telethon попросит авторизоваться в Telegram. После этого будет создан локальный session-файл.

## Настройки качества

- `similarity_threshold`: чем выше значение, тем строже объединение похожих новостей. Обычно хорошо работает диапазон `0.78–0.88`.
- `lookback_hours`: за какой период собирать новости.
- `max_messages_per_channel`: лимит сообщений на канал за один проход.
- `min_text_length`: минимальная длина поста, чтобы отсеять рекламу, эмодзи и короткие репосты.

## Рекомендации по эксплуатации

- Запускайте агента по cron или systemd timer, например раз в 1–3 часа.
- Для приватных каналов аккаунт Telegram должен быть подписан на эти каналы.
- Для снижения дублей добавьте в источники только первичные каналы и надежные агрегаторы.
- Если дайджест слишком короткий — уменьшите `similarity_threshold`; если разные новости склеиваются — увеличьте его.
